# Cartão de Visitas Digital

Cartão de visitas digital da Isabela de Oliveira Alves, com foto, bio e links para
LinkedIn, GitHub, portfólio e e-mail. Inclui alternância entre tema claro e escuro.

🔗 Acesse o site: https://isabelacss.github.io/mavi-click/

## Como iniciar

1. Clone o repositório.
2. Abra o `index.html` no navegador ou use a extensão Live Server no VS Code.

## Estrutura
```
mavi-click/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
├── assets/
│   └── foto.png
└── README.md
```

## Tecnologias

- **HTML5**: estrutura semântica do cartão, com `header`, `nav` e `footer`.
- **CSS3**: estilização das cores, responsividade com media queries e os temas claro e escuro.
- **JavaScript**: alternância entre os temas, com a preferência salva no navegador via `localStorage`.

Escolhi HTML, CSS e JavaScript puros, sem frameworks, para dominar os fundamentos
e manter o projeto leve e sem dependências.
